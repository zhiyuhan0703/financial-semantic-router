# Data Notice

The issuer names, exchange labels, and security codes in `frozen/public-v1.0/companies.json` are public factual identifiers. The aliases are a small, newly selected lookup vocabulary for this experiment.

All queries, conversation histories, family labels, and expected routing decisions in `cases.jsonl` were newly authored for this repository. They are not copied from a private competition set, seminar workspace, provider logs, or an external benchmark.

The public synthetic dataset and code are released under the repository's MIT License. No financial statement values, personal data, API responses, or investment recommendations are included.
